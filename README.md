##  Projetos em Destaque

###  Dashboard Interativo: Monitoramento de Produtividade Pública
**[Clique aqui para visualizar o Dashboard Interativo](https://rocha-matheus.github.io/portfolio/dashboard-ministerio-publico.html)**
*   **Descrição**: Visualização avançada de métricas de produtividade e composição de acervo processual.
*   **Tecnologias**: HTML5, CSS3, JavaScript, Chart.js.
*   **Destaque**: Uso de Controle Estatístico de Processo (CEP) e decomposição de séries temporais para detecção de anomalias.
*   **Nota**: Dados 100% anonimizados/sintéticos para fins de demonstração técnica.

###  Projeto 01: Pipeline ETL de Dados Médicos
**[Ver Notebook: 01_SQL_Python_ETL.ipynb](01_SQL_Python_ETL.ipynb)**
*   **O Que Faz?**: Pipeline completo de ETL para consolidar dados de múltiplos arquivos Excel, aplicando filtros inteligentes e removendo duplicatas.
*   **Dataset**: ~1.138 registros brutos consolidados em 307 registros únicos e limpos.
*   **Tecnologias**: Python, DuckDB, Pandas, Regex.

###  Projeto 02: Previsão de Evasão Escolar (Sklearn)
**[Ver Notebook: 02_Python_Sklearn_Classification.ipynb](02_Python_Sklearn_Classification.ipynb)**
*   **O Que Faz?**: Classificação e previsão de evasão e permanência de alunos baseados em dados comportamentais.
*   **Tecnologias**: Python, Scikit-learn, Pandas, Seaborn.
