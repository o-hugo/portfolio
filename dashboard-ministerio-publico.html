O que esta aba mostra

A aba Produtividade conta movimentos (atos processuais como juntadas, baixas, manifestações). Esta aba conta processos únicos que estavam no inventário entre 2024 e 2025. Por isso os números são menores.

Aqui o foco não é "quantos atos foram registrados", e sim o que está no acervo, quanto já foi finalizado e quanto tempo leva. Cada barra dos gráficos mostra três informações de uma vez: volume (tamanho da barra), taxa de finalização (rótulo em %) e tempo mediano em dias até o desfecho.

Notas Metodológicas (Ambiente Demonstrativo)
Sobre este Projeto
Informações sobre a construção e o propósito do dashboard.

Objetivo: Este dashboard foi criado para demonstrar habilidades em visualização de dados, engenharia de front-end com Chart.js e análise estatística aplicada a fluxos processuais públicos.

Dados: Os números apresentados aqui são gerados de forma sintética (mockups) ou anonimizados. Nomes de unidades, assuntos e classes foram alterados para garantir total privacidade e conformidade com boas práticas de segurança de dados.

Tecnologias: HTML5, CSS3 (Vanilla), JavaScript, Chart.js. A lógica de negócio no back-end (não visível aqui) envolveu processamento de grandes volumes de dados via Python e SQL antes da exportação para este formato estático de alta performance.
